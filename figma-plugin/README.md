# PPT Library Manager — Figma 플러그인

피그마에서 **템플릿(여러 페이지)·요소(단일)를 라이브러리에 등록**하고,
**무엇이 등록돼 있는지 플러그인 안에서 미리보기로 조회**합니다. 등록분은 `app/library.js`로 내보내거나 백엔드로 전송.

## 설치 (개발 모드)
1. Figma Desktop → Plugins → Development → **Import plugin from manifest…**
2. `figma-plugin/manifest.json` 선택 → 실행

## ➕ 등록 탭
- **모드 선택**: `템플릿(여러 페이지)` / `요소(단일)`
- **템플릿**: 페이지로 쓸 **프레임들을 다중 선택** → 이름·문서종류(사업계획서/IR Deck/제안서)·태그 입력 → **템플릿 등록**
  - 선택한 각 프레임 = 1페이지. 크기(16:9/4:3)·배경·팔레트 자동 추출.
- **요소**: 프레임 **1개 선택** → 이름·카테고리(통계/텍스트/강조/도형/리스트)·태그 → **요소 등록**
  - 요소는 0-base 좌표 + `base`(기준 폭)로 저장 → 앱에서 페이지 크기에 맞게 자동 스케일.

## 📚 라이브러리 탭
- 등록된 **템플릿/요소를 썸네일 미리보기 + 메타(종류·크기·페이지수·태그)** 로 목록 조회
- 각 항목 **삭제**, **전체 비우기**
- **🚀 앱에 동기화** 칸에 `https://<프로젝트>.vercel.app/api/library` 를 한 번 넣어두면
  → **이후 등록할 때마다 즉시 자동으로 원격(/api/library)에 push** 됩니다. (웹앱 새로고침 시 반영)
- 수동 옵션: **library.js 스니펫 복사 / JSON 다운로드** 로도 반영 가능.

## 저장 위치
- `figma.clientStorage` (사용자 로컬, 영구). 팀 공유는 백엔드 전송으로.

## 출력 스키마 (앱과 동일)
```jsonc
// 템플릿
{ "id","name","docType","size","tags":[],"palette":[],
  "pages":[ { "size","w","h","bg","statics":[ … ], "groups":[] } ] }
// 요소
{ "id","name","category","tags":[],"w","h","base",
  "nodes":[ { "type":"text|rect", "x","y","w","h", … } ] }
```

## v2 출력 (현재) — v2 빌더 트리 모델 + 색상 6역할
템플릿 등록은 이제 **v2 트리 모델**로 직렬화됩니다(`{ v:2, theme, pages:[{title,subtitle,body}] }`). v2 빌더(`/v2.html`)의 **📥 Figma 가져오기**(JSON 붙여넣기 또는 동기화 URL)로 들어옵니다.

### 디자이너 작성 규약 (이대로 만들면 깔끔하게 변환됨)
1. **프레임 1개 = 슬라이드 1장** (1920×1080 권장), 페이지 순서대로 다중 선택.
2. **색상 6역할 = Figma Variables**: 색 변수 이름을 `accent / bg / surface / text / subtext / line` 으로(컬렉션명 자유, 경로 끝 토큰 기준, 대소문자 무시). 채움/글자색/선색을 이 변수에 **바인딩**. → 등록 탭 **🎨 색역할 스캔**으로 `6/6 ✓` 확인 후 등록.
3. **헤더 텍스트**: 레이어 이름 `#title`, `#subtitle` → 페이지 제목/부제(본문에서 자동 제외).
4. **바디 = 오토레이아웃**: 가로(HORIZONTAL)→행, 세로→열. 간격=itemSpacing, 패딩 유지, `layoutGrow>0` 자식→비율(weights).
5. **블록 타입(레이어명 태그)**:
   - 텍스트: 무태그→본문, `@title`→제목.
   - 컨테이너: `@kpi`(텍스트 2개=숫자·라벨)→KPI, `@list`(텍스트 줄바꿈/여러 텍스트)→리스트.
   - **텍스트 없는 그룹/벡터/아이콘** → 고화질 PNG 이미지 블록.
   - 채움 있는 컨테이너 → 카드/섹션 배경(역할 색 적용).

### 검증
- 등록 후 **🚀 앱에 동기화**(또는 JSON 다운로드) → v2 빌더 **📥 Figma 가져오기**에 붙여넣기 → 페이지 랜딩 확인.
- **테마 리믹스** 시 `accent` 역할만 retone, `surface/text` 등은 유지(역할 토큰 동작 확인).
